# Python_biocientistas_unesp
Material da disciplina de Introdução ao Python para Biocientistas da pós-graduação em Ciências Farmacêuticas da UNESP. Focado em biotecnologia e bioprocessos, capacita pesquisadores a utilizarem programação para automação, análise biológica de dados, unindo tecnologia e pesquisa científica de forma prática.
